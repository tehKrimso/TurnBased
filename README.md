### Turn-Based Strategy Prototype
A turn-based tactics game prototype in the style of XCOM, built in Unity as part of "Unity Turn Based Strategy: Code Your Own Strategy Game" course by GameDev.tv

### About
A complete tactical gameplay loop with alternating player and enemy turns, grid-based movement and flexible action system for each unit.

### Implemented systems
- Turn management - alternating turns between player and enemy sides, each controling all thheir units before passing the turn.
- Grid movement - squre-cell grid system for unity positioning and navigation. Including hex-grid refactoring.
- Pathfinding - A* algorithm implemented for movement calculation.
- Action point systems - each unit has a pool of action points spent on actions per turn.
- Unity actions - movement, shooting, grenade throw, melee attack.

### Tech
- Engine: Unity
- Language: C#
